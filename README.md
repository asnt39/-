# 2D RPG 전투 테스트

Godot 4.6 프로젝트. 모바일은 왼쪽 조이스틱과 오른쪽 확인·공격·대시 버튼을 사용합니다. PC는 WASD 또는 방향키 이동, J 공격, Shift 대시, E 확인, 1~4 교체입니다. 선택지에서는 1 또는 2를 누릅니다. F 공격과 Enter 확인도 유지합니다.

파티에는 김찬유와 교체 검증용 임시 동료가 있습니다. 임시 동료는 정식 합류 설정이 아닙니다. 동료는 공격하지 않습니다. 대시에는 현재 무적이 없습니다. 궁극기는 추후 구현 예정입니다. 대화 중 저장·불러오기는 제한됩니다. 기존 저장 파일을 불러올 수 있습니다. 전투 중 적 상태는 저장하지 않습니다.

그래픽과 대사는 테스트용입니다. 글꼴은 Noto Sans CJK KR의 현재 사용 문구만 추출했습니다. 새 문구 추가 시 글꼴을 재생성해야 합니다. 라이선스는 assets/FONT-LICENSE.txt를 확인하세요.
