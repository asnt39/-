# 2D RPG 테스트 프로토타입

Godot 4.6에서 `project.godot`을 열어 실행합니다. 모바일은 가로 화면에서 왼쪽 조이스틱과 오른쪽 확인 버튼을 사용합니다. PC는 방향키/WASD와 E/Enter/스페이스를 사용합니다. 선택지는 클릭하거나 1번 선택은 Enter, 2번 선택은 2 키를 누릅니다.

대상을 바라보고 가까이에서 확인을 누릅니다. 대화 중에는 저장과 불러오기가 잠시 제한됩니다. 저장은 브라우저의 로컬 데이터에 남으며 브라우저 데이터 삭제 시 사라질 수 있습니다.

한국어 폰트는 Noto Sans CJK KR에서 현재 테스트 문구에 필요한 글자만 추출했습니다. 새 대사를 넣을 때 폰트 글자를 다시 포함해야 합니다. 라이선스는 `assets/FONT-LICENSE.txt`를 참고하세요. 그래픽과 인물, 대사는 테스트용입니다.
