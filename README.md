# RPG 프롤로그

Godot 4.6에서 `project.godot`을 열어 실행합니다. 마을 사람에게 말을 걸어 소문을 듣고 동쪽 출구에서 확인을 누르세요. 들판의 슬라임을 물리친 뒤 동쪽 숲 입구에서 확인을 누르면 프롤로그가 끝납니다.

PC: WASD 또는 방향키 이동, J 공격, Shift 대시, E/Enter 확인. 모바일: 조이스틱 이동, 공격·대시·확인 버튼. 대화 중 저장과 불러오기는 제한됩니다. 목표, 슬라임 체력, 파티와 위치는 저장됩니다. 이전 프로토타입 저장은 프롤로그 미진행으로 불러옵니다. 브라우저 데이터 삭제 시 저장도 삭제될 수 있습니다.

`story_data.gd`에서 대사를 수정할 수 있습니다. 한국어 폰트는 현재 사용 문구를 기준으로 축소되어 있어 새 문구 추가 시 글꼴을 재생성해야 합니다. 폰트 라이선스는 `assets/FONT-LICENSE.txt`에 있습니다. 스토리 이후 구성은 `STORY_PLAN.md`를 참고하세요.
