# RPG 개발 빌드

마을 사람에게 소문을 듣고 동쪽 들판의 슬라임을 물리친 뒤 동쪽으로 이동하세요. 숲, 산길, 마왕성 앞에서 동료를 차례로 만날 수 있습니다. 새 구역과 영입 대사는 테스트용이며 보스전은 아직 없습니다.

PC: WASD/방향키 이동, J 기본 공격, K 특수 공격, Shift 대시, E 확인, 1~4 교체. 모바일: 왼쪽 조이스틱, 오른쪽 버튼, 왼쪽 파티 버튼. 대화 중 저장과 불러오기는 제한됩니다.

현재 특수 공격의 캐릭터별 배정은 임시입니다. 저장은 브라우저 로컬 데이터에 저장되며 브라우저 데이터 삭제 시 사라질 수 있습니다. 기존 저장은 계속 읽을 수 있습니다.

대사는 story_data.gd에서 수정합니다. 한국어 글꼴은 현재 사용 문구를 기준으로 축소했으므로 문구 추가 시 갱신해야 합니다. 라이선스는 assets/FONT-LICENSE.txt를 확인하세요.
